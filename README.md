# Aban Pharmaceuticals — Official Website

The official website for **Aban Pharmaceuticals**, a trusted pharmaceutical company established in 1981, based in Bavla GIDC, Ahmedabad, Gujarat, India.

🌐 Live Site: [www.abanpharmaceuticals.com](https://www.abanpharmaceuticals.com)

---

## Project Structure

## Features

- Welcome splash screen with company branding
- Responsive navbar with mobile toggle
- Hero section with animated typing text
- About section with 40+ years experience badge
- Product categories grid (Analgesic, Antibiotic, Antacid, Anti Cold, Anti Fungal, General Range, Nutraceuticals)
- Searchable accordion product list with 100+ formulations
- Facilities and quality assurance section
- Contact page with direct call and WhatsApp buttons
- Floating WhatsApp button and back-to-top button
- SEO optimized with Schema.org structured data and Open Graph tags
- Google Analytics integration

## Getting Started

This is a static website — no build step required.

1. Clone or download the repository
2. Open `index.html` in a browser, or serve with any static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```
